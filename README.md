# Go

A Go programming language learning repository with example scripts and code snippets.

## Contents

### Main Files

- `hello.go` - Basic "Hello World" example demonstrating print statements
- `hello_var.go` - Demonstrates variable declarations, constants, and data types in Go
- `doc.go` - Documentation reference for Go variable syntax

### Challenge Scripts

Located in the `challenge/` directory:

- `script_print_5_hello.go` - Loop example that prints "Hello" multiple times
- `script_print_all_files.go` - File system example that lists directory contents
- `script_print_random_password.go` - Random password generator using runes and randomization

## Getting Started

### Prerequisites

- Go 1.16 or higher installed on your system

### Running the Examples

```bash
# Run the hello example
go run hello.go

# Run the variable examples
go run hello_var.go

# Run challenge scripts
go run challenge/script_print_5_hello.go
go run challenge/script_print_all_files.go
go run challenge/script_print_random_password.go
```
